# Security

This repository holds plain Markdown skill files. It has no code, no dependencies, and no build step.

## What never goes in here

- API keys, tokens, passwords, or any credential.
- Client names, contact data, account IDs, or any personal data.
- Content copied from third parties without a license that allows it.

## Reporting a problem

If you find a secret, personal data, or content that should not be public, do not open a public issue. Use GitHub's private vulnerability reporting on this repository (Security tab > Report a vulnerability). We aim to answer within 5 business days.

## Using these skills safely

The skills draft, review, and recommend. They are written not to change anything in a GoHighLevel account. Test each skill in your own sub-account before using it with a client, and review its output before you send or apply anything.
