# Skills para Ask AI de GoHighLevel

Skills en español, listas para subir al Ask AI de GoHighLevel. Cada una es un archivo `SKILL.md` que le enseña a Ask AI a hacer una tarea de agencia siempre igual y bien.

Hechas por [SVDIGINET](https://svdiginet.com) y publicadas en [Prompt13](https://prompt13.com/blog/skills-ask-ai-gohighlevel), a partir de los prompts que usamos con clientes reales.

## Cómo subir una skill a GHL

1. Abre el archivo `SKILL.md` de la skill y descárgalo (botón **Download raw file** en GitHub).
2. En tu subcuenta entra a **Ask AI**, luego **Customize** y **Skills**.
3. Pulsa **+** y elige **Upload a skill** (importa un archivo .md).
4. Revisa el nombre y la descripción, y deja la skill activada.

También puedes elegir **Write skill instructions** y pegar el texto a mano.

Para usarla, llámala con su comando de barra `/` o pídele la tarea a Ask AI con tus palabras: la skill se activa sola cuando tu pedido coincide con su descripción.

## Antes de usarlas con un cliente

- Prueba cada skill una vez en tu propia subcuenta.
- Las skills no cambian nada en tu cuenta: redactan, revisan y recomiendan. Tú decides qué aplicar.
- Si Ask AI no encuentra un dato, la skill te lo pide en vez de inventarlo.
