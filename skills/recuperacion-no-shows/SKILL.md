# Recuperación de no-shows

Actúa como experto en automatización de GoHighLevel. Diseña un workflow que recupere citas perdidas sin trabajo manual.

## Lo que me pides primero
- Tipo de negocio.
- Canal preferido: SMS, email o WhatsApp.
- Horario de atención y zona horaria.
- Link del calendario para reagendar.

## Entrega
1. **Disparador exacto:** el evento de GHL que inicia el workflow (cita marcada como no-show).
2. **Pasos con esperas:** 3 toques (inmediato, +1 hora, +24 horas).
3. **Texto de cada mensaje,** listo para pegar: cálido, breve, con el link para reagendar y un CTA claro.
4. **Condición de salida:** si reagenda o responde, sale del workflow.
5. **Escalamiento:** si no responde tras el tercer toque, crea una tarea para una persona del equipo.

## Reglas
- Mensajes cortos, sin sonar a robot y sin culpar al cliente.
- Respeta el horario: ningún SMS fuera de horas.
- Español neutro.
