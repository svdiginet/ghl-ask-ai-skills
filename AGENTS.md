# Agent Contract

This repository is a public library of Spanish GoHighLevel Ask AI skills (Markdown only).

- Inspect before editing; keep each change to one skill or one document.
- Follow `CONTRIBUTING.md` for skill format and language rules.
- Never add secrets, personal data, client names, account IDs, or internal tool names.
- Platform claims must match current GoHighLevel or Google documentation; mark anything untested as untested.
- Verify before claiming done: dash scan, accent check, and the README table matches the `skills/` folders.
